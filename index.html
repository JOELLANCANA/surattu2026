Pertanyaan yang Sering Diajukan (FAQ)

Jawaban atas pertanyaan seputar tata persuratan, pengarsipan, dan pelacakan surat di UIN Ar-Raniry Banda Aceh.

Bagaimana cara melacak surat yang telah dikirim ke UIN Ar-Raniry?
Anda dapat menggunakan kotak pencarian cepat di bagian atas halaman (Hero) atau pada bagian 'Pusat Cek & Arsip Dokumen Publik'. Cukup ketik nomor surat, instansi asal, atau perihal surat untuk melihat status penerimaan dan agendanya secara langsung.
Di mana dokumen dan lampiran surat fisik disimpan?
Setiap lampiran digital surat dipindai dan disimpan secara aman di Google Drive institusi UIN Ar-Raniry Banda Aceh. Metadata surat direplikasi secara otomatis ke Google Sheets dan Cloudflare Workers KV berkecepatan tinggi demi menjaga keutuhan dan redundansi data.
Apakah sivitas akademika dapat melihat surat keluar kampus?
Ya, daftar nomor agenda dan perihal surat keluar yang telah berstatus resmi dapat dilihat pada tabel 'Arsip Surat Keluar' untuk mendukung keterbukaan informasi dan mencegah duplikasi nomor dinas.
Bagaimana jika nomor surat belum tercatat di sistem?
Surat yang baru masuk melalui loket administrasi umum biasanya memerlukan waktu verifikasi dan penomoran agenda singkat oleh petugas piket. Silakan hubungi petugas persuratan di Gedung Biro Rektorat UIN Ar-Raniry jika memerlukan tindak lanjut darurat.
Bagaimana teknologi Cloudflare Workers & Pages diintegrasikan?
Sistem Si-Surat telah dilengkapi modul sinkronisasi otomatis ke Cloudflare Workers KV (Namespace ID: 99b98313726f42c9a197d5b98e760629), memastikan aplikasi tetap memiliki database cadangan di jaringan edge global berkinerja tinggi.

Panduan Deploy Cloudflare (Workers & Pages)

✨ Database Tersimpan Otomatis ke CloudflareSelain tersimpan ke Google Spreadsheet & Google Drive, setiap surat baru atau data master pengirim/tujuan langsung otomatis disimpan ke database Cloudflare (Workers KV / D1 / API).

🚀 Opsi 1: Deploy ke Cloudflare Pages (Rekomendasi)

Jalankan perintah ini di terminal proyek Anda:

npx wrangler pages deploy . --project-name=si-surat-uin-arraniry

Atau hubungkan repositori Git di dash.cloudflare.com (Build command: npm run build, Output directory: .).

⚡ Opsi 2: Deploy ke Cloudflare Workers

Proyek ini sudah memiliki worker.js dan wrangler.toml siap pakai:

npm run deploy:worker

🗄️ Database Cloudflare KV (Terkonfigurasi)

Binding KV SURAT_KV telah terpasang di wrangler.toml:

[[kv_namespaces]]
binding = "SURAT_KV"
id = "99b98313726f42c9a197d5b98e760629"

Pada Cloudflare Pages Dashboard, cukup kaitkan binding variable SURAT_KV ke namespace ID tersebut di Settings > Functions.

Panduan Deploy ke Vercel

▲ Vercel Production ReadyAplikasi ini adalah situs HTML statis. Vercel menyajikan index.html; data surat tetap menggunakan Google Apps Script yang sudah dikonfigurasi.

🚀 Cara 1: Menggunakan Vercel CLI (1 Menit)

Jalankan di terminal lokal Anda:

npx vercel --prod

🌐 Cara 2: Import dari GitHub ke Vercel

  1. Buka vercel.com/new.
  2. Pilih repositori Git yang berisi file index.html dan vercel.json.
  3. Biarkan Framework Preset sebagai Other dan Root Directory ./.
  4. Klik Deploy. Selesai! Website langsung aktif di domain *.vercel.app.
Catatan backendDeploy ini hanya menerbitkan antarmuka web. Google Apps Script dan izin akses spreadsheet tetap harus aktif agar data dapat dimuat dan disimpan.
